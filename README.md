# Student Placement Dashboard

A responsive, browser-only React application for managing placement opportunities, applications, interviews, company research, notifications, and student profiles.

## Features

- Secure demo authentication with local persistence
- Protected routes for authenticated students
- Placement dashboard with application analytics
- Search, filter, sort, and apply for jobs
- Application tracking with status updates
- Interview scheduling and readiness overview
- Company discovery and role information
- Notification management
- Editable student profile
- Light and dark themes
- Responsive layout for desktop, tablet, and mobile

## Tech Stack

- React 19
- Vite
- React Router
- Recharts
- Lucide React
- Context API
- localStorage

## Getting Started

```bash
npm install
npm run dev
```

Open the URL printed by Vite, usually http://localhost:5173.
